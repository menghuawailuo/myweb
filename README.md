# 橱柜对账

装修橱柜快速报价 / 对账工具。手机浏览器打开即用，可「添加到主屏幕」当成 App，断网也能查。

## 怎么用

1. 打开页面 → 底部「＋ 记一笔」新建一个工程（填地址、厂房、设计师、单价，并选录入方式）。
2. 进工程 → 「＋ 添加柜子」，选计价方式、填尺寸，支持「保存并继续」连续录入。
3. 同一页往下有「＋ 杂项」，灯管、指纹锁这类按件算的东西记在这里（和柜子平级，不用挂到某个柜子下面）。
4. 底部「统计」看一份年报式的战绩回顾（金额、柜子排行、高光时刻）；「我的」里有备份和主题色。

### 两种录入方式

新建工程时选，之后可以在「✎ 编辑工程」里随时改。**两种方式算出来的钱完全一样**，只是录入和显示的路子不同，随时来回切换都不会丢数据。

| 方式 | 录入路径 | 适合 |
|---|---|---|
| **直接列柜子**（默认） | 打开工程就能加柜子，不用先建房间 | 一次报完一整套，柜子之间不用分区 |
| **按房间分类** | 先建厨房 / 主卧等房间，柜子放进对应房间 | 分区域对账，需要按房间出小计 |

选「直接列柜子」时：

- 柜子列表是平铺的一列，仍然可以拖动排序。
- 账单、打印、PDF、Excel 里不出现房间分组标题，行数更少。
- 从「按房间分类」切过来的话，柜子会带一个灰色房间标签，让你知道它原来属于哪间。
- 「统计」页的房间分布只统计按房间录入的工程，会有一行小字说明。

程序会记住你上次选的录入方式，下次新建默认就是它。「分类」页里的「房间分类」词表只在有按房间录入的工程时才显示。

### 四种计价方式

| 方式 | 公式 | 用途 |
|---|---|---|
| 面积计价 | 宽 × 高 × 数量 × 单价 | 常规柜体，按 m² 报价 |
| 延米计价 | 长度 × 数量 × 单价 | 橱柜地柜、台面 |
| 按件计价 | 数量 × 单价 | 拉手、五金、按个算的柜子 |
| 固定金额 | 直接填总额 | 一口价的项目 |

> 只有**面积计价**的柜子会算进工程总面积，其余三种不计，避免面积虚高。

### 杂项（与柜子同级）

灯管、指纹锁、反弹器这类东西**不挂在柜子底下**，而是和柜子并排记在房间里。一行「数量 × 单价」，有自己独立的金额和账单行，也不计入面积 —— 灯管再多也不会让房子变大。

- **添加**：房间里（直列模式就在柜子列表下面）点「＋ 杂项」，或直接点快捷标签「灯管 ¥10/个」「指纹锁 /套」。
- **修改**：名称、数量、单位、单价都能就地改，点走（失焦）就自动存下来。
- **删除**：每行右边的 ✕。
- 点出来什么都没填就离开，那一行会自动收掉，不会在账本里留垃圾行。
- 账单、打印、PDF、Excel 里都是一行独立条目，和柜子同样缩进，用浅灰底跟柜子区分开。

> 老版本的数据里杂项是挂在柜子上的，打开时会自动搬到所属房间，**金额一分不变**。

### 折扣与收款

- 折扣支持两种写法：**折扣率**（填 `9.5` 或 `95` 都表示 95 折，填 `10` = 原价）或**直接减免金额**。
- 「已结清」开关打开时会把「已收」自动回填成应收金额，关掉则清零 —— 每次变动都能在「已收」框里看到。
- 收款情况实时显示为「已收 / 未收」，未收金额不会显示成负数。

### 导出（顶栏「⋯」）

导出是低频操作，放在页面正中间会一直挡着录柜子，所以收进了右上角的「⋯」菜单里，和微信的「更多」一个路子：

| 菜单项 | 说明 |
|---|---|
| ⧉ 复制账单 | 复制成纯文本，直接粘贴到微信发人 |
| 🖨 打印/存PDF | 调用浏览器打印，选「另存为 PDF」得到**矢量文字**的 PDF，可搜索可选中 |
| 📄 导出PDF | 生成图片式 PDF，版式固定，长账单自动分页且不会截断表格行 |
| 📊 导出Excel | 生成 .xlsx，可继续在表格里改 |
| 🗑 删除工程 | 和导出让开一道线，删之前照旧自动留「后悔药」 |

后三个导出需要联网加载一次组件（约几百 KB），加载过之后离线也能用。

#### 报表里的单位

**每一列的单位都写在表头，格子里只留数字** —— 一列一百行不会把同一个「m」抄一百遍：

```
名称        规格(m×m)   数量(个/套)  面积(m²)  单价(元/m²)  金额(元)
地柜        2×0.6       3           3.6      200          720
吊柜        1.8×0.7     2           2.52     260          655.2
衣柜        2.4×2.4     1           5.76     380          2188.8
灯管        —           6           —        10 元/个     60
指纹锁      —           1           —        480 元/套    480
```

两处例外，都是为了不让格子里的数字失去说法：

- **数量表头按表里实际用到的单位汇总。** 柜子一律按「个」数，杂项用它自己的单位，所以表头是 `数量(个/套)`；哪天杂项改成按米算，表头会跟着变成 `数量(个/米)`。
- **延米柜的规格自带 `m`**（`2.4m`）—— 只有一个长度，写 `2.4` 会被当成 `m×m` 的一半。

单价这一列有两种写法，**看工程里用了几种计价方式**：

- 全表只有一种（绝大多数工程）：基准（元/m²、元/m、元/个）写进表头。
- 混着用了好几种（一个工程里既有面积计价的地柜、又有延米计价的台面）：表头盖不住，退回 `单价(元)`，把基准标到**每一行**上。这样表头永远不会对某些行说谎。

杂项不参与这个单价判断 —— 灯管按个、指纹锁按套，那是它自带的单位，一直跟在行里。

PDF 和 Excel 共用同一份判断逻辑，两边的表头永远一致。

#### PDF 的结尾

表格最后一行是加重的**应收金额**，整张单子就落在这一个数上。

单子上**不出现「已收」「未收」** —— 那是自己跟客户的账，印在给客户的对账单上就成了催款单。收款情况在工程页和「统计」里看（「复制账单」里仍有，那是你自己看的）。

#### PDF 体积

「导出PDF」出的是图片式 PDF，所以体积全看位图怎么压：

- 渲染倍数从 3 降到 2（A4 横向约 180 DPI，印出来清清楚楚，再高肉眼也看不出差别，文件却要翻倍）。
- 每一页分别按 PNG 和 JPEG 各编一份，**谁小用谁**：白底黑字的表格 JPEG 通常小好几倍，而大片留白的短账单反而是 PNG 更小。这样既拿到压缩，又保证任何一页都不会比原来更大。

### 统计页（年报感）

「统计」不是一张冷冰冰的报表，而是一份把辛苦记下来的战绩回顾 —— 从上往下看：

| 板块 | 内容 |
|---|---|
| 📖 你和柜子的故事 | 应收合计（全部时间），外加一句收款状态：没收回来的钱「在外流浪」，收完了就「完美收工」 |
| 成就牌 | 接了多少单、做了多少个柜子、量了多少 m²、结清了几单、记了几笔杂项 |
| 高光时刻 ✨ | 最大的一单、做得最多的「王牌柜子」、最忙的一个月、这个账本是从哪天开始记的 |
| 排行 | 柜子排行（谁是你的当家花旦）、杂项排行、工程金额排行 |
| 月度趋势 | 按「装修时间」归月的柱状图，可展开看每月明细 |

**柜子排行**是按柜子**名字**归并的，跨工程统计「地柜做了多少次、一共多少钱」—— 直列录入没有房间层级，这张榜比房间分布有用得多。

「房间金额分布」只在你有按房间分类录入的工程时才出现；全是直列工程时它不会占地方。

### 工程信息与收款（默认收起）

设计师、装修时间地点这些**只在新建时填一次**的信息，和默认单价、折扣、已收金额一起收进了一张「工程信息与收款」卡片，进工程时默认是合上的 —— 打开工程就能直接看到柜子列表，不用先滑过一堆设置。

收起时卡头右边有一行摘要（`张三 · 9.5折 · 未收 ¥1234`），不展开也知道现在的收款状态。点卡头即可展开，重新进入工程时又会回到收起状态。

## 数据存在哪

**只存在你这台设备的浏览器里**，不会上传到任何服务器。所以：

- 换手机、换浏览器、清理浏览器数据 → 数据会没。
- 「我的」页有 **备份数据**（下载一个 .json 文件）和 **导入备份**，建议每次录完一批就导出一次存到微信收藏或网盘。
- 超过 7 天没备份，首页会提醒；也可以点「稍后」推迟一天。
- 删除工程、清空数据、导入备份之前，程序会自动留一份「后悔药」，在「我的」页可以一键还原上一个时间点。

## 部署 / 开发

纯静态页面，无构建、无依赖：

```
index.html    界面结构
css/style.css 样式
js/calc.js    计算核心（纯函数，不碰 DOM）
js/app.js     界面与数据层
sw.js         Service Worker（离线缓存）
manifest.json PWA 配置
tests/        测试
```

跑测试：

```bash
node tests/calc.test.js     # 51 项：算法、折扣、杂项、浮点误差、账单对不上账
node tests/app.smoke.js     # 56 项：界面初始化、增删改、导出、备份恢复、两种录入方式、折叠面板、年报统计
```

两个都不需要装任何依赖。

### ⚠️ 必须通过 http(s) 打开，不能双击文件

直接双击 `index.html` 用 `file://` 协议打开时，浏览器会禁用 **Service Worker**（离线缓存 / 安装成 App 失效）和 **剪贴板 API**（「复制账单」按钮会退化）。数据保存通常还能用，但体验不完整。

本地起一个服务器：

```bash
python -m http.server 8080     # 然后访问 http://localhost:8080
# 或
npx serve .
```

要部署到网上，把这个文件夹整个传到任意静态托管即可（GitHub Pages、Vercel、Netlify、对象存储 + CDN 都行），必须是 **HTTPS**。

### 改完代码记得升版本号

修改 `index.html` / `css` / `js` 之后，把 `sw.js` 里的 `CACHE = 'cabinet-v11'` 往上加一号，否则老用户会一直用旧缓存。用户在页面打开时会收到「已更新，是否刷新」的提示。

### 加新计价方式 / 改算法

计算逻辑全部集中在 `js/calc.js`，界面层不重复实现任何金额公式。改完先跑 `node tests/calc.test.js` —— 那里盯着四种计价方式、杂项、折扣钳制、浮点误差，以及「账单上各行相加必须等于小计」这条不变量。
